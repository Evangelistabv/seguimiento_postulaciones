# Ruta laboral

Aplicación Django para registrar y dar seguimiento a postulaciones laborales, entrevistas, tareas y próximos pasos.

## Ejecutar en local

```bash
python3 manage.py migrate
python3 manage.py runserver
```

Abre `http://127.0.0.1:8000/`. La migración inicial incluye la vacante de ejemplo tomada del rastreador de Excel.
